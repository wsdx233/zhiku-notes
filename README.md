# 知库

本地优先的笔记与资料知识库。开发使用 Vite，构建结果为单个静态 HTML。

## 运行

```sh
npm install
npm run dev
npm test
npm run build
```

构建后打开 `dist/index.html`，也可部署到静态网站。脚本、样式、字体和文档解析 Worker 均内嵌，无需从 CDN 加载解析资源。

## 只读资料

点击知识库内容旁的添加资料图标。

- Markdown 和 TXT 保持原有笔记编辑方式
- PDF、DOCX、PPTX、XLSX、HTML 使用 DocMarrow 提取正文
- CSV、TSV、JSON、JSONL、XML、YAML、LOG、INI、TOML、RST 作为只读文本资料
- 单份资料最多 30 MB，压缩包解压后的总内容最多 100 MB
- 保留原始文件，可下载原件，也会包含在知识库 ZIP 备份中
- 提取缓存保存在 IndexedDB，外部文件变更后重新解析
- 资料与包含资料的目录不能被编辑、重命名、移动或删除
- 可移除整个知识库连接，移除本地连接不会删除磁盘文件

预览仅显示提取内容，不保留 Office 原始排版，不执行 HTML 脚本，也不加载资料中的远程图片。

不支持旧版 DOC、PPT、XLS，以及 RTF、ODT、EPUB。不包含 OCR 或视觉模型，扫描页、图片与图表可能无法读取。PPTX 不读取演讲者备注。XLSX 使用已有公式缓存，不重新计算。加密文档需先解密。

## 知识助手

- `list_files` 区分笔记与只读资料
- `search_files` 检索资料正文，并返回来源与分段序号
- `read_file` 通过 `offset` 和 `limit` 分段读取，返回 `nextOffset`
- 引用提供文件路径、章节路径，PDF 额外提供页号
- 解析警告和失败会返回给助手，不把失败资料当成已经完整读取
- 工具执行层阻止修改资料及操作其父目录，不仅依赖模型提示词
- 短文档也可作为对话附件，长文档应导入知识库以供分段读取

文档解析在本机进行。使用知识助手时，所读取的内容会发送到用户配置的模型接口。

## 本地目录

安全上下文支持目录句柄时，可直接连接本地文件夹。只有笔记编辑会写回，资料始终只读。

不支持直连或处于非安全上下文时，使用标准目录选取导入快照。快照保存在浏览器中，不会同步或写回原文件夹，不保留空目录。也可从知识库菜单主动选择导入文件夹快照。

## 测试

单元测试覆盖格式解析、长文档分页、只读保护、原件备份恢复、目录快照及外部变更缓存失效。

安装 Chrome 后运行浏览器验收：

```sh
npm run test:browser
```

可用环境变量 `CHROME_BIN` 指定 Chrome 可执行文件。

验收覆盖六类资料、原件下载、重载恢复、ZIP 备份往返、非安全上下文目录选择、离线打开单个 HTML，以及 HTML 脚本和远程图片隔离。Agent 工具循环使用本地模拟接口，不发送真实文档到外部模型。

生产构建使用经典内嵌 Worker，避免本地文件来源下模块 Blob Worker 的兼容问题。
